<title>Validação end-to-end das fichas React</title>

A migração React de D&D 5E, Call of Cthulhu e Vampiro V5 foi concluída.

Agora NÃO quero uma nova migração nem uma refatoração estrutural.

Quero somente validar o funcionamento real da integração React com o sistema legado.

## OBJETIVO

Comprovar que os três sistemas realmente conseguem:

```text
Criar ficha
↓
React
↓
main.ts
↓
handlers existentes
↓
StorageService
↓
SistemaPasta
↓
localStorage
↓
reabrir ficha
↓
React
↓
editar
↓
salvar
↓
reabrir novamente
```

---

# 1. NÃO ALTERAR A ARQUITETURA

Não modificar:

* backend;
* PostgreSQL;
* migrations;
* Mobile;
* autenticação;
* Dashboard;
* Mestre;
* projeto de referência;
* arquitetura React já criada;
* SistemaPasta;
* StorageService.

Não migrar novos módulos.

Não criar uma nova persistência.

Não criar outro serviço de armazenamento.

Não alterar o modelo de dados apenas para fazer o teste passar.

---

# 2. PRIMEIRO ANALISAR

Antes dos testes, verifique como atualmente funcionam:

* `ReactSheetBridge.ts`;
* `App.tsx`;
* `main.tsx`;
* `main.ts`;
* `JogadorView.ts`;
* `StorageService.ts`;
* `SistemaPasta.ts`;
* `DndCharacterModule.tsx`;
* `CocCharacterModule.tsx`;
* `VampireCharacterModule.tsx`;
* views guiadas dos três sistemas.

Identifique exatamente:

1. onde React envia os dados;
2. onde `main.ts` recebe os dados;
3. onde os handlers coletam os campos;
4. onde `StorageService` salva;
5. onde a ficha é recuperada;
6. onde React recebe novamente os dados.

Não altere nada somente durante essa análise.

* Classe: `Guerreiro`
* Nível: `5`
* Força: `16`
* Destreza: `14`
* HP máximo: `50`
* CA: `16`

4. salvar;
5. fechar;

# 6. TESTE DE ISOLAMENTO DOS SISTEMAS
